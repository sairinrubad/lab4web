## Pengertian HTML dan CSS

**HTML (HyperText Markup Language)** adalah bahasa markup yang digunakan untuk menyusun struktur halaman web, seperti judul, paragraf, gambar, tautan, formulir, dan bagian konten lainnya.

**CSS (Cascading Style Sheets)** adalah bahasa stylesheet yang digunakan untuk mengatur tampilan halaman web, termasuk warna, ukuran tulisan, jarak, posisi elemen, dan tata letak.

HTML berfungsi untuk membangun struktur halaman, sedangkan CSS mengatur tampilannya agar lebih menarik dan mudah dibaca. Keduanya digunakan dalam praktikum ini untuk membuat layout halaman web sederhana.
